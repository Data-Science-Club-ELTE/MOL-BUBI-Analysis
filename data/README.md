# Data Directory Layout

- `data/raw/`: External raw datasets (DEM rasters, raw WorldPop GeoTIFFs, frozen OSM PBFs, BKK API dumps). Ignored by git.
- `data/processed/`: Contract-compliant Parquet/GeoParquet tables generated by the project pipeline.
- `data/cache/`: Routing cache dictionaries, intermediate OSMnx graph pickles.
- `tests/fixtures/`: Tiny, committed toy datasets (Budapest Belváros) used for unit testing and offline development.
